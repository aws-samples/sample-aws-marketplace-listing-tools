# AWS Marketplace SaaS Integration Tester Workshop

## About this workshop

This workshop helps AWS Marketplace sellers validate their SaaS listing integrations before submitting for MCO (Marketplace Channel Operations) review.

## Modules

- **[Test Your SaaS Listing Integration](./en-US/)** — Deploy the test tool and validate all required integrations end-to-end

## Target audience

AWS Marketplace sellers who have a SaaS listing in Limited state and are preparing for MCO review.

## Duration

~20 minutes
